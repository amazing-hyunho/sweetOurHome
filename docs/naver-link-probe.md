# 공유 링크 파싱 검증 — 2026-10-15

입력: https://naver.me/xEXYkQ4W

로그인하지 않은 브라우저에서 성복역현대홈타운 단지의 매매 목록으로 연결됐다.
화면 기준 462세대, 2001년 2월 입주 표기. 최초 로딩 중 매매 0, 로딩 완료 후 15로 바뀌었다.

실제 렌더링된 카드 텍스트를 로컬에 추출하고 lib/naver-snapshot.mjs로 파싱했다.

- 매매 카드 15개 (중개사 묶음 포함, 실제 주택 수나 개별 광고 수와 동일하지 않음)
- 직접 확인한 개별 매물 링크/ID 11개
- 개별 ID 미확정인 중개사 묶음 카드 4개
- 정확한 층수 3개, 저/중/고 표기로 층 미확정 12개
- 가격 단위는 만원, 전용면적은 ㎡, 미확정 층수는 null

전체 개별 매물 목록이 완성됐다고 표시하지 않는다. 묶음 펼치기와 단지 ID 식별은 별도 구현/검증이 필요하다.
한 번 읽은 값으로 가격 변화나 급매 여부를 판단하지 않는다. 비교 실거래와 사용자 목표 가격은 이번에 확보하지 않았다.

동일 입력 URL로 일반 Node fetch를 한 번 실행했다. 응답 HTTP 200, HTML 약 156KB였으나 단지명/샘플 매물 ID/전용면적 필드는 HTML에서 찾지 못했다. 브라우저 렌더링 후 목록을 읽는 경로가 필요하다. 내부 API 호출, 접근 제한 우회, 반복 조회는 수행하지 않았다.

원본 카드의 핵심 텍스트와 파싱 결과는 Git 제외 경로 local/link-probe/에만 저장했다.
Firebase에는 이번 추출 결과를 게시하지 않았다. 페이지는 반복적·체계적 복제/전송에 관한 제한 안내를 표시한다. 자동 수집 경로와 사용 조건 검증은 남아 있다.

파서는 화면 카드 배열을 입력받는 순수 함수다. 브라우저 실행/단축 링크 해석/예약 수집/Firebase 갱신 기능이 아니다.
