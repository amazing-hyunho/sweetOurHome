# 낮 12시 호가·매물 변동 알림

한국시간 매일 낮 12시 Windows 로그인 자동 실행 프로세스가 `node scripts/daily-digest.mjs`를 실행합니다. PC가 켜져 있고 Windows에 로그인된 상태여야 합니다. Codex는 필요하지 않습니다. 12:00~12:29 이외에는 전송하지 않습니다. 해당 시각 최신 성공 수집(30분 이내)을 직전 비교 기록과 비교합니다. 수집은 기존 10분 주기이므로 정확히 12시에 네이버를 새로 조회하는 것은 아닙니다.

- 개별 매물 ID별 호가 변경, 새로 관찰한 매물, 이번 수집에서 미확인된 매물을 단지별 요약합니다.
- 변동이 없으면 보내지 않습니다. 목표 가격 충족 여부와는 별도입니다.
- 부분 수집에서 사라진 매물을 삭제·거래 완료로 판단하지 않습니다.
- 오래된 수집·수집 실패·수집 끄기 상태인 단지는 비교를 보류하고 이전 비교 기록을 유지합니다. 다음 성공일에는 마지막 비교 이후 누적 변동을 알립니다.
- 첫 설정은 `node scripts/daily-digest.mjs --baseline`으로 전송 없이 기준 기록을 저장합니다. 이후 재실행해도 기준은 덮어쓰지 않습니다.
- `--preview`는 비교 결과만 출력하며 전송·기준 갱신을 하지 않습니다.
- 같은 날 재실행해도 중복 발송하지 않습니다. 전송 결과가 불확실할 때 자동 재전송하지 않습니다.

수신 대상은 목표액 알림과 같은 PC `observer/telegram.json`입니다. 일별 기준과 발송 기록은 `observer/daily-digest.sqlite`에 보관합니다. 예약 작업 프롬프트에는 토큰을 넣지 않습니다.
