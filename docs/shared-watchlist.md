# 공동 관찰 앱 — 합의와 구현 상태

## 확정한 방향

- 두 사람이 구글 계정으로 로그인해 하나의 공동 목록을 관리한다.
- GitHub Pages는 화면 배포, Firebase Spark는 공유 데이터, 집 PC는 수집과 알림 담당.
- PC 중단 시 수집/알림 중단을 감수하며, 최신 성공 시각을 표시한다.
- 네이버 단지/매물 링크 등록. 단지 전체를 관찰하고 직접 추가한 매물은 찜으로 구분.
- 단지와 매물 각각 메모 CRUD, 작성 시각/작성자 표시.
- 매매 아파트, 전용 59㎡ 이상, 400세대 이상, 정확한 층 3층 이상. 불명확한 층은 확인 대상.
- 비교는 같은 단지 최근 6개월, 면적 ±0.5㎡, 3층 이상, 취소 제외, 3건 이상 중앙값. 5% 이상 할인 후보.
- 목표 가격은 단지/정확한 전용면적별 입력. 비교 거래 부족 시 설정한 목표만 사용.
- 급매 후보 또는 찜 가격 인하 시 공동 Telegram 그룹에 24시간 알림. 동일 상태 중복 전송 금지.
- 변경 후 10분 이내 발견은 희망 목표이며 공급원의 반영 속도와 수집 경로 검증이 선행되어야 한다.

## 이번 구현

지역/단지/매물 CRUD, 찜 표시와 필터, 단지/매물 메모 CRUD, 면적별 목표 가격, 백업에 새 필드 보존.
면적을 지정하지 않은 기존 목표 가격은 보존하되 자동 후보 판단에서 제외하고 재설정 안내.
동일 링크 중복 등록 방지(문자열 동일 기준). 단축 링크와 원본 링크의 동일성 해석은 미구현.
Firebase 선택적 연결, Google 로그인, 멤버 접근 규칙, 구독/버전 충돌 감지 코드 준비.

## 아직 연결하지 않은 기능

- 무료 Firebase 프로젝트 생성, 규칙 게시, 두 계정 실사용 검증
- 링크에서 단지/매물 정보 자동 추출 (현재 이름/가격/면적 등 직접 입력 필요)
- 자동 수집과 가격 이력 DB, Telegram 봇 및 그룹 연결
- 수집 데이터 전용 컬렉션과 자동 알림 중복 방지 저장소

## 보라매삼성 수집 검증 — 2026-10-12

공식 네이버 공개 API 목록에서 부동산 매물 API를 확인하지 못했다.
이번 웹 조회 도구의 https://fin.land.naver.com/complexes/48 열기는 Internal Error로 실패했다.
이 결과만으로 사이트가 다운됐거나 자동 수집이 불가능하다고 판단하지 않는다.
기존 2026-10-10 브라우저 수동 확인에서는 단지와 개별 매물 정보를 읽었으나 반복 수집을 검증하지 않았다.
내부 API 429 응답을 우회하거나 재시도하지 않았다. 현재 반복 수집 경로는 확보되지 않았으며 수집 성공으로 표시하지 않는다.

공식 API 목록: https://developers.naver.com/products/intro/plan/plan.md

## 검증

로컬 Node 테스트 15개 통과(그중 기존 개인 금융 모듈 테스트 6개는 배포 저장소에 포함하지 않음).
빌드 및 JS 문법 검사 통과. 브라우저에서 메모 추가/읽기/수정과 새로고침 후 유지 확인.
메모 삭제 UI 테스트는 브라우저의 확인창 자동화가 멈춰 완료 여부를 검증하지 못했다.
Firebase 실서비스 연결 및 규칙의 에뮬레이터 테스트는 미실행. 연결 전 검증 절차는 firebase-setup.md에 명시했다.
