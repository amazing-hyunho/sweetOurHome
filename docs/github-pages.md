# GitHub Pages 운영

배포 주소: https://amazing-hyunho.github.io/sweetOurHome/

브라우저별로 관심 지역·단지·매물 설정을 저장합니다. 다른 기기에서 같은 설정을 쓰려면 관찰 설정에서 JSON 백업을 다운로드한 뒤 해당 기기에서 복원해주세요. 복원은 현재 기록 전체를 교체합니다.

로컬 PC 서버의 기존 기록은 자동 업로드하지 않습니다. 로컬 버전에서 JSON 백업을 받아 공개 버전에서 복원할 수 있습니다. 백업은 서버에 업로드되지 않고 브라우저에서 읽습니다.

배포에는 웹앱 파일과 초기 보라매삼성 단지 정보만 포함합니다. `local`, `outputs`, 개인 데이터 파일은 배포하지 않습니다. GitHub Actions는 main 변경 시 테스트·빌드 후 Pages를 배포합니다.

자동 매물 수집과 텔레그램 알림은 미연결입니다.
