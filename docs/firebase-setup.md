# Firebase 공개 공동 목록

사용자 요청에 따라 로그인 없이 누구나 공동 목록을 조회·수정한다.
Google Authentication 및 members 등록은 더 이상 필요하지 않다.

1. Firebase Console > Firestore > Rules에서 저장소의 firestore.rules 전체 내용을 붙여넣고 게시한다.
2. 웹앱을 새로고침한다. 로그인 없이 공동 목록이 표시되어야 한다.
3. 다른 기기에서 변경 반영을 확인한다.

공개 범위는 households/home 문서 하나다. 전체 데이터베이스를 개방하지 않는다.
문서 삭제는 금지하지만 목록 안의 단지·매물·메모 삭제는 누구나 가능하다.
기존 메모도 공개 조회 대상이다. 작성자 이름은 신원 확인 없이 방문자로 표시한다.
스키마 및 버전 검사를 유지하지만 공개 쓰기에 따른 변조나 무료 사용량 소진을 방지하지는 않는다.

웹 설정은 연결되어 있다. 콘솔 규칙 게시 여부는 별도로 확인해야 한다.
기존 기기별 데이터는 자동 업로드하지 않는다. JSON 복원은 공동 목록 전체를 교체한다.
수집기와 Telegram은 아직 미연결이며, 공동 목록 문서는 JSON 700KB로 제한한다.
