# 일별 호가 추이

관심 단지에 등록한 링크의 수집이 성공하면 정확한 전용면적별 최저·최고 호가와 개별 매물 수를 Firebase 단지 기록에 함께 저장합니다. 한국시간 날짜 기준으로 하루 마지막 성공 수집이 해당 날짜의 값을 대체합니다. 당일 전체 관측의 최저·최고가 아니며, 묶음 매물·이전 수집에서만 남은 매물은 집계하지 않습니다.

웹의 관심 단지 카드에 면적별 그래프와 펼쳐보는 날짜별 표를 표시합니다. 하루만 있으면 점으로 표시하고, 수집이 없거나 해당 면적이 없는 날은 연결하지 않습니다. 실거래가가 아닌 수집된 매물의 호가이며 매물 구성에 따라서도 범위가 변합니다.

최근 365개 기록일을 보관합니다. JSON 백업에도 포함됩니다. 별칭 변경은 기록을 유지하지만 단지 링크 변경은 다른 단지가 섞이지 않도록 기록을 초기화합니다. 단지 삭제 시 기록도 삭제됩니다. PC가 꺼지면 새로운 기록이 쌓이지 않습니다. 기존 최신 수집분은 `node scripts/seed-daily-history.mjs`로 실제 관찰 날짜에 한해 추가할 수 있습니다.

공동 문서의 기존 용량 한도가 적용됩니다. 여러 단지를 장기간 대량 관리하면 별도 시계열 저장소로 이전이 필요합니다. 저장 실패는 기존 기록을 유지하며 수집 오류 로그에 표시됩니다.

그래프의 일단위·주단위·월단위 버튼으로 표시 단위를 선택합니다. 주는 월요일~일요일, 월은 달력 월 기준이며 해당 기간 마지막 성공 수집을 표시합니다(평균이나 기간 전체 최저·최고가 아님). 표에는 실제 수집 날짜도 표시됩니다. 선택은 단지별로 페이지를 사용하는 동안 유지되며 원본 일별 기록은 변경하지 않습니다.
