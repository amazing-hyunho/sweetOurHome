# 목표 가격 텔레그램 알림

관심 단지 → 조건 편집 → 면적별 목표 가격에 `84.85, 110000`처럼 전용면적(㎡), 목표액(만원)을 저장합니다. 해당 면적의 가격이 목표액 **이하**이면 전송합니다. 층수·세대수 조건은 적용하지 않습니다. 목표를 지우면 알림을 중단합니다.

`setup-telegram.cmd`를 실행하면 토큰을 화면에 표시하지 않고 입력하고 수신 대화를 선택한 뒤 연결 확인 메시지를 보냅니다. @BotFather에서 /newbot으로 만든 봇에 먼저 /start를 보내세요.

수동 설정은 PC의 `%LOCALAPPDATA%\sweetOurHome\observer\telegram.json`에 아래 형식으로 기존 봇 정보를 저장합니다. 토큰은 웹이나 GitHub에 올리지 마세요.

```json
{"token":"봇 토큰", "chatId":"대화 ID"}
```

`start-target-alerts.cmd` 실행: Firebase를 1분마다 확인합니다. 수집기는 `collect-python.cmd`로 별도 실행해야 합니다(10분 주기). PC 종료 시 둘 다 멈춥니다. 재부팅 후 다시 실행하세요. 중단은 `stop-target-alerts.cmd`입니다.

최초 실행에도 조건을 만족하는 매물을 알립니다. 성공한 최신 수집분 중 30분 이내 데이터만 사용합니다. 실패한 단지, 수집을 끈 단지, 이전 수집에서만 발견된 매물은 제외합니다. 동일 매물·가격은 SQLite에 기록하여 재시작, 목표 수정 후에도 중복 전송하지 않습니다. 다른 가격은 새 알림 대상입니다. 전송 결과가 불확실하면 중복 방지를 위해 자동 재시도하지 않습니다.

설정 파일은 PC에만 보관합니다. 웹의 안내는 실행 확인 표시가 아닙니다. 실행 창 또는 PC의 `observer/targets.sqlite`에서 전송 결과를 확인하세요. 기존 `observe.mjs`의 급매 후보 알림과 별도 동작하므로 동시에 사용하면 두 종류의 알림을 받을 수 있습니다.
